# ContinueRetro Source Bridge v1 — ส่งต่อเฉพาะซอร์สแอป

**นี่ไม่ใช่ตัวอัปเดต Studio และไม่เปลี่ยนการติดตั้งบนไดรฟ์เดิม**

รันไทม์แชทยังเปิด ZIP ไม่ได้ ส่วน GitHub และเครื่องมืออ่านไฟล์ข้อความยังทำงานได้ ตัวช่วยนี้อ่าน ZIP ตัวแอป v0.6.0 ที่มีอยู่ใน Mac แล้วแปลงเฉพาะซอร์สที่อนุญาตเป็นไฟล์ TXT เพื่อให้ตรวจและเชื่อมงานต่อจากโค้ดจริง ไม่ใช่สร้างแอปใหม่จากรายงาน

## ใช้บน Mac

1. แตกแพ็กตัวช่วยจนเห็น `PREPARE_STUDIO_SOURCE.command` อยู่ข้าง `source_bridge.py`
2. เปิด `PREPARE_STUDIO_SOURCE.command` แล้วเลือก **ContinueRetro_Studio_ExternalDrive_v0.6.0.zip เดิม** ไม่ใช่ ZIP เกม และไม่ใช่ ZIP ตัวช่วยนี้
3. เมื่อเสร็จ จะมีโฟลเดอร์ `ContinueRetro_Source_Handoff_v0.6.0_02c3aa9f1102` อยู่ข้าง ZIP ที่เลือก แนบ **CONTINUERETRO_V060_SOURCE.txt** จากโฟลเดอร์นั้นกลับในแชท

ไม่ต้องส่ง London, FontKit, BIOS หรือฐานข้อมูลซ้ำ ไม่ต้องเปลี่ยน Ollama และไม่ต้องปิดแอปเพื่อใช้ตัวช่วย เพราะตัวช่วยไม่เปิดไฟล์ของการติดตั้งเดิม อ่านเพียงแพ็ก ZIP ที่คุณเลือก

หาก ZIP อยู่ในโฟลเดอร์เขียนไม่ได้ ใช้คำสั่ง `--output-parent` ชี้ไปยังโฟลเดอร์ที่มีอยู่บนไดรฟ์ภายนอก โปรแกรมไม่สร้างพาธแทนไดรฟ์ที่หาย และไม่เขียนทับผลลัพธ์เดิมที่ต่างกัน

```bash
python3 source_bridge.py --zip "/พาธ/ContinueRetro_Studio_ExternalDrive_v0.6.0.zip" --output-parent "/Volumes/ชื่อไดรฟ์/โฟลเดอร์ที่มีอยู่"
```

ต้องมี Python 3.10 ขึ้นไป เช่น Python ที่ใช้เปิด Studio เดิม ไม่ต้องติดตั้งไลบรารีเพิ่มเติม ไม่มีคำสั่ง sudo หรือคำสั่งปิดระบบป้องกัน macOS

## ขอบเขตที่ตรวจและข้อมูลที่ไม่ถูกส่งออก

- ตรวจ SHA-256 ทั้ง ZIP ก่อนอ่านสมาชิก โดยรับแพ็ก v0.6.0 แฮช `02c3aa9f1102b5b00191c20f37e7c061bf225bc5c5305d40bb105560f1bc297e` เท่านั้น CLI ไม่มีตัวเลือกข้าม hash
- รับเฉพาะซอร์ส Python, หน้าเว็บ, config และข้อความความรู้ในตำแหน่งที่กำหนด พร้อมโค้ดทดสอบและสคริปต์เข้าโปรแกรมบางรายการ
- ไม่เปิดหรือรันโค้ดใน ZIP ไม่เรียกตัวติดตั้ง และไม่อัปโหลดผลลัพธ์ขึ้น GitHub หรือบริการใด
- ไม่อ่านโฟลเดอร์ PRIVATE ของเครื่องผู้ใช้ และไม่รวมเกม ฟอนต์/ข้อมูล glyph โมเดล ฐานข้อมูล รูปภาพ log หรือ binary fixture
- ตรวจชื่อพาธ symlink ชื่อซ้ำ case collision UTF-8 ขนาดข้อมูล และ CRC ของไฟล์ข้อความที่อ่าน
- บันทึก SHA-256 และจำนวนไบต์ของทุกไฟล์ที่ส่งออก รายการที่ข้ามอยู่ใน SOURCE_INDEX.json
- ผลลัพธ์ถูกตรวจการอ่านกลับ และไฟล์เก่าที่ตรงกันใช้ซ้ำได้โดยไม่แก้เวลาไฟล์; ถ้าผลลัพธ์ต่างกันจะหยุดแทนเขียนทับ

TXT เป็นซอร์สที่อ่านได้ ไม่ใช่สำเนาแอปสำหรับติดตั้ง: binary fixture และไฟล์ที่ไม่อยู่ใน allowlist ถูกข้ามตามเจตนา ก่อนรัน regression ทั้งแอปต้องตรวจว่าทรัพยากรที่จำเป็นมีครบ ไม่ถือว่าตัวช่วยนี้ตรวจแอป v0.6.0 ผ่านแล้ว

แฮชภายใน bundle ใช้ตรวจความครบถ้วนของการส่งต่อ ไม่ใช่ลายเซ็นรับรองผู้ส่งหรือการรับรองว่าโค้ดปลอดภัย ผู้รับยังต้องตรวจโค้ดก่อนนำไปทำงาน

## ทดสอบตัวช่วย

จากโฟลเดอร์ตัวช่วย:

```bash
python3 -m unittest test_source_bridge.py -v
```

ชุดทดสอบสร้าง ZIP สังเคราะห์ขึ้นเอง ไม่รันบน ROM/ฟอนต์/ฐานข้อมูลของผู้ใช้ และไม่ได้ใช้ผลนี้แทนการทดสอบ London หรือการคลิก Finder บน Mac จริง ดู `VALIDATION.txt` และ `BUILD_INFO.json` ในแพ็กที่ GitHub Actions สร้างสำหรับ commit และผลรันที่เกี่ยวข้อง

## งานที่จะเดินต่อเมื่ออ่าน TXT ได้

ตรวจ API/storage/worker/frontend ในซอร์ส v0.6.0 จริง → เชื่อม quality.py และ review_payload.py ที่เก็บไว้ → ทดสอบฐานเดิมและการเชื่อม → ปรับ UI สามหมวด/Score/Technical QA/Human Review โดยไม่รื้อหลังบ้าน

London ยังเป็นเกมนำร่องเพียงเกมเดียว การแกะ–ประกอบเกมจริงและ Runtime QA ยังรอระบบที่เข้าถึงไฟล์และเครื่องมือได้ ไม่ถือว่า helper นี้ทำเกมผ่านแล้ว
