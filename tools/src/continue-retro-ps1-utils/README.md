# ContinueRetro PS1 utilities

Tracked project-owned tools so ad-hoc analysis never lives only in `/tmp`:

- `sjis_scan.py` — CP932/Shift-JIS candidate extraction.
- `raw2352.py` — raw 2352-byte image inspection and safe-copy byte patch helper.
- `disc_manifest.py` — `dumpsxiso` XML to CSV LBA map.
- `psxexe_info.py` — PS-X EXE header/hash inspector.
